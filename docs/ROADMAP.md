# Silio launch roadmap

## Website implementation

Completed: bilingual positioning for small businesses, website, web application and mobile app development as the core offers, 49 scoped packages, dedicated bilingual pages for every service, interactive fictional demos, package comparison, project estimator, free website review requests, campaign attribution, and enquiry validation.

Email delivery is implemented but requires owner-supplied Resend configuration. GitHub stores source code; pushing this repository does not deploy a hosted website.

## Owner setup before public launch

- Set `NEXT_PUBLIC_SITE_URL` to the domain you own and configure hosting and DNS.
- Configure the three Resend environment variables using a verified sender.
- Add host-level rate limiting / bot protection and test a real enquiry to your mailbox.
- Confirm the phone number, service availability, price scopes, translations, retention policy and support capacity.
- Set up the real WhatsApp Business, Instagram and Facebook accounts. Add social links only once actual profiles exist.
- Review eligibility before applying for a Google Business Profile. No profile or ad account has been created by this implementation.
- Prepare permission-based local demonstrations and a brochure using the finalized offers. No campaigns, outreach messages or ad spend have been initiated.

## First-month activity checklist

### Week 1: foundation

- [ ] Publish the configured English/Hindi website.
- [ ] Set up WhatsApp Business and social profiles.
- [ ] Customize the working demos for permission-based presentations.
- [ ] Prepare a service and pricing brochure.

### Week 2: local discovery

- [ ] Research 40 relevant businesses.
- [ ] Aim for 10 permission-based introductory conversations.
- [ ] Show demos to interested businesses.
- [ ] Record objections and service requests privately.

### Week 3: conversion

- [ ] Publish three educational posts or reels.
- [ ] Offer proposals with explicit scope and deliverables.
- [ ] Follow up only with interested leads.
- [ ] Aim to begin one or two paid projects; this is a target, not a forecast.

### Week 4: improve

- [ ] Complete projects and collect feedback.
- [ ] Obtain permission before publishing real case studies.
- [ ] Offer ongoing care plans where useful.
- [ ] Review leads, conversions, revenue, project expenses and time spent.

## Future private CRM phase

The supplied strategy describes a private admin area as a later phase. A protected `/admin` dashboard now implements enquiry capture, status tracking, file downloads and first-party analytics. Full quotations, projects, invoices and scheduled follow-ups remain future work. MongoDB and password-protected admin sessions are configured locally; production needs its own secrets, trusted network access and an enquiry retention policy.

Suggested records: enquiries; source campaign tags; new/contacted/quoted/won/lost status; consent-aware follow-up dates; quotations; projects; and invoices. Do not store these in public assets, source control, browser-only admin dashboards or an unauthenticated API.

## Marketing experiments

Start with demos and conversations. The strategy's ₹3,000 monthly scenario allocates ₹1,200 to ad experiments, ₹750 to local materials, ₹600 to content and ₹450 to reserve. These are planning figures, not expenses incurred, commitments or predicted results. Actual accounts, spending and outreach require separate owner action.

## 3D service launch

Implemented: bilingual 3D overview, seven scoped 3D services, per-service pages, indicative printing estimator and bounded model email attachments. The portfolio includes an illustrative enclosure concept only.

Before accepting physical orders: confirm an actual print provider, materials, available machines, quality checks, sample approval process, delivery arrangements and the final itemized price. Do not claim an owned printer or unsupported certification. A live model viewer, automatic slicing, instant manufacturing quotes and online order payments are future work.

## Current service priority

The owner has confirmed website development, web application development and mobile app development as the main focus. UI/UX, 3D design/printing and other specialist services remain secondary. The earlier small-business starter offers remain available, but are no longer the main featured packages.
